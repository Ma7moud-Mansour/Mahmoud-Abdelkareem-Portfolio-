# Mahmoud Abdelkareem — Portfolio Identity

## Direction

The portfolio translates the visual language of Al-Mansour Academy into a personal software-engineering brand: deep navy for authority, warm orange for momentum, and soft off-white for clarity. The result should feel precise, optimistic, technically capable, and distinctly human.

This is a personal portfolio, not an academy clone. The shared identity appears through color, spacious composition, technical linework, circular orange geometry, compact labels, and strong calls to action.

## Core palette

- Deep Navy: `#061F46` — primary dark surface, footer, expertise section, code panels
- Navy Mid: `#0A2E63` — layered dark surfaces and hover states
- Warm Orange: `#F28C00` — primary actions, emphasis, badges, visual anchors
- Orange Bright: `#FF9D0A` — active and hover states
- Off-white: `#FAF8F3` — page background
- Paper: `#FFFEFB` — cards and bright content areas
- Ink: `#092856` — primary text on light surfaces
- Muted: `#6D7C92` — supporting text
- Mint: `#57D3B2` — availability and success signals only

## Typography

- Primary: Manrope — headlines, navigation, body copy, controls
- Technical: IBM Plex Mono — labels, metadata, code, indexes, statuses
- Headline style: bold, tight tracking, compact line height
- Body style: calm rhythm, generous line height, moderate measure

## Visual language

- Large orange circles and thin orbital lines reference the academy hero artwork.
- Navy code windows provide a recognizable engineering signature.
- Small numbered indexes make the page feel intentional and editorial.
- Cards use thin borders and tonal contrast rather than heavy glass effects.
- Corners are soft but controlled: 8–18px for UI, 20–26px for major panels.
- Motion is restrained: gentle reveals, small lifts, and slow floating accents.

## Layout

- Maximum content width: 1180px
- Desktop sections use generous 100–125px vertical spacing.
- Mobile uses an 18px side gutter and single-column content.
- The hero is a 2-column editorial layout that collapses into a centered stack.
- Projects use one flagship card with supporting cards, then a dedicated archive.

## Voice

Copy is confident, direct, and product-minded. Avoid generic claims and inflated titles. Prefer specific language about intelligent products, dependable systems, thoughtful interfaces, and useful outcomes.

## Accessibility

- Maintain strong contrast between navy, orange, and off-white.
- Every interactive control requires visible keyboard focus.
- Motion respects `prefers-reduced-motion`.
- Images use descriptive alt text.
- Navigation exposes expanded/collapsed state on mobile.
